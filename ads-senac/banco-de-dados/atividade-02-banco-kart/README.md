#  Sistema de Gestão de Corridas de Kart

Atividade desenvolvida durante o curso Técnico em Análise e Desenvolvimento de Sistemas do SENAC, utilizando MySQL para criar e manipular um banco de dados relacional de uma associação de kart.

## Objetivo

Desenvolver um banco de dados para armazenar informações sobre temporadas, etapas, equipes, patrocinadores e pilotos participantes de um campeonato de kart.

## Atividades desenvolvidas

- Criação do banco de dados e das tabelas conforme o diagrama Entidade-Relacionamento.
- Inserção dos dados fornecidos no guia da temporada de kart.
- Atualização das cidades de duas etapas do campeonato.
- Exclusão do patrocinador da equipe Corredores de Aço.
- Consulta e exibição dos dados dos pilotos.

## Scripts SQL

- **Criação:** estruturação do banco de dados e das tabelas.
- **Inserção:** inclusão dos dados da temporada, equipes, patrocinadores e pilotos.
- **Manipulação:** atualização, exclusão e consulta de registros.

## Tecnologias

- MySQL
- MySQL Workbench
- SQL

## Conhecimentos praticados

- Criação de bancos de dados e tabelas.
- Modelagem de dados relacionais.
- Inserção de registros (`INSERT`).
- Atualização de dados (`UPDATE`).
- Exclusão de registros (`DELETE`).
- Consulta de dados (`SELECT`).
