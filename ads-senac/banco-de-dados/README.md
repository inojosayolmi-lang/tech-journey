# Banco de Dados — SENAC

Esta pasta reúne atividades práticas desenvolvidas durante minha formação em Análise e Desenvolvimento de Sistemas no SENAC, com foco em modelagem, criação, manipulação e consulta de bancos de dados relacionais.

## Atividades

### UC3 — Banco de Dados

- **Atividade 1 — Modelagem de Banco de Dados:** elaboração de um Diagrama Entidade-Relacionamento (DER) para uma plataforma de streaming.
- **Atividade 2 — Sistema de Gestão de Corridas de Kart:** criação, inserção e manipulação de dados utilizando scripts SQL.
- **Atividade 3 — Consultas SQL:** consultas e análises de dados em um banco de dados de uma plataforma de jogos.

## Tecnologias e ferramentas

- MySQL
- SQL
- MySQL Workbench

## Conhecimentos praticados

- Modelagem de bancos de dados relacionais.
- Entidades, relacionamentos e cardinalidade.
- Criação e manipulação de tabelas.
- Inserção, atualização e exclusão de registros.
- Consultas e relacionamento entre tabelas.
