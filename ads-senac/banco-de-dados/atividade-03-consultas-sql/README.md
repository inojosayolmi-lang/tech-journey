# Atividade 3: Consultas SQL

Atividade prática desenvolvida durante o curso Técnico em Análise e Desenvolvimento de Sistemas do SENAC, utilizando SQL para realizar consultas em um banco de dados de uma plataforma de jogos.

## Objetivo

Consultar e analisar informações sobre usuários, jogos, desenvolvedoras, categorias e bibliotecas de jogos.

## Consultas desenvolvidas

- Busca de usuários por data de cadastro.
- Consulta de jogos por faixa de preço.
- Busca de jogos de desenvolvedoras específicas.
- Cálculo do preço médio dos jogos.
- Cálculo do valor total dos jogos na biblioteca de um usuário.
- Identificação do jogo mais caro de uma desenvolvedora.
- Consulta de jogos por categoria.
- Listagem de usuários e seus jogos.
- Contagem de jogos por país da desenvolvedora.

## Tecnologias

- MySQL
- SQL
- MySQL Workbench

## Conhecimentos praticados

- Consultas com `SELECT`.
- Filtros com `WHERE`.
- Relacionamento entre tabelas com `JOIN`.
- Funções de agregação (`AVG`, `SUM` e `COUNT`).
- Ordenação com `ORDER BY`.
- Limitação de resultados com `LIMIT`.
