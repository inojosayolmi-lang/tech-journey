# CoffeeNet — Etapa I

**Projeto Integrador I — SENAC**

A primeira etapa do CoffeeNet corresponde à fase de planejamento e estruturação do sistema de gestão para cafeterias.

O objetivo é definir as funcionalidades, os requisitos e a estrutura do banco de dados que dará suporte às operações do sistema.

## Entregas da etapa

### 1. Documentação técnica

Documento com a apresentação do CoffeeNet, descrição do sistema, perfis de usuários, permissões e requisitos funcionais e não funcionais.

### 2. Modelagem do banco de dados

Elaboração do Diagrama Entidade-Relacionamento (DER), definindo as entidades, os atributos, as chaves e os relacionamentos necessários para a estrutura do sistema.

### 3. Banco de dados

Desenvolvimento da estrutura do banco de dados utilizando SQL, com definição das tabelas e seus relacionamentos.

## Tecnologias e ferramentas

- MySQL
- MySQL Workbench
- SQL

## Objetivo da etapa

Estabelecer a base técnica do CoffeeNet, organizando os requisitos e a estrutura de dados que servirão de referência para as próximas etapas do projeto.

## Próximas etapas

O desenvolvimento do CoffeeNet continuará em etapas posteriores, com novas entregas e evolução gradual do sistema.
