# UX/UI Design

Esta pasta reúne projetos de prototipação e design de interfaces, com foco na organização visual, experiência do usuário e navegação entre telas.

## Projetos

### Sistema de Gerenciamento — Pizzaria Sr. Manoel

Protótipo de um sistema desktop para gerenciamento de uma pizzaria, desenvolvido no Figma.

**O projeto contempla:**
- Wireframes e estruturação das telas.
- Protótipo interativo.
- Tela de login.
- Controle de caixa.
- Cadastro de clientes.
- Fluxos de navegação entre telas.

**Materiais disponíveis:**
- Protótipo interativo no Figma.
- Documentação visual do projeto em PDF.
