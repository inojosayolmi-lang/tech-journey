# Sistema de Gerenciamento — Pizzaria Sr. Manoel

Protótipo de um sistema desktop para gerenciamento de uma pizzaria, desenvolvido no Figma.

## Objetivo

Propor uma interface organizada para auxiliar nas atividades administrativas da pizzaria.

## Funcionalidades prototipadas

- Tela de login e tratamento de acesso inválido.
- Controle de caixa, com registro de entradas e saídas.
- Visualização do saldo.
- Cadastro de clientes.
- Navegação entre as telas do sistema.

## Ferramenta utilizada

- Figma
