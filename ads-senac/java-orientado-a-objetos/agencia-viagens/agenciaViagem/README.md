# Agência de Viagem

Projeto desenvolvido , utilizando Java e conceitos de Programação Orientada a Objetos.

## Sobre o projeto

O Agência de Viagem é uma aplicação desenvolvida para simular o cálculo de pacotes de viagem, considerando informações de transporte, hospedagem, duração da viagem, margem de lucro e taxas adicionais.

O sistema também realiza a conversão do valor final de dólares para reais, utilizando a cotação informada pelo usuário.

## Funcionalidades

- Organização das informações de transporte e hospedagem.
- Cadastro e cálculo de pacotes de viagem.
- Cálculo de custos e margem de lucro.
- Aplicação de taxas adicionais.
- Cálculo do valor total da viagem.
- Conversão de dólares para reais.

## Estrutura do projeto

O projeto foi organizado em classes:

- `Transporte`
- `Hospedagem`
- `PacoteViagem`
- `Venda`
- `AgenciaViagem`
