# Java — Orientação a Objetos

Esta pasta reúne projetos e exercícios em Java, explorando conceitos de programação e orientação a objetos.

## Projetos

### 1. Agência de Viagem
Aplicação para simulação de pacotes de viagem, com cálculos de transporte, hospedagem, taxas, margem de lucro e conversão de valores monetários.

### 2. SistemaRH
Sistema de gerenciamento de funcionários, com cadastro de colaboradores assalariados e horistas, cálculo de remunerações e aplicação de reajustes.

### 3. SistemaImposto
Aplicação para cálculo de tributos, com implementação dos cálculos de PIS e IPI, utilizando interfaces e listas para organizar os impostos.

## Tecnologias e ferramentas

- Java
- NetBeans IDE

## Conceitos explorados

- Programação Orientada a Objetos (POO).
- Classes, objetos e métodos.
- Encapsulamento e herança.
- Classes abstratas e interfaces.
- Polimorfismo.
- Listas e coleções.
- Operações matemáticas e lógica de programação.
