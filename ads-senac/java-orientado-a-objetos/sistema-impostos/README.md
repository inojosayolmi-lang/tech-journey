# SistemaImposto

Aplicação Java para cálculo de tributos, contemplando PIS e IPI. O sistema recebe os dados necessários para cada operação, realiza os cálculos e organiza os resultados por meio de interfaces e classes.

## Funcionalidades

- Cálculo do PIS com base nos valores de débito e crédito.
- Cálculo do IPI considerando alíquota, valor do produto, frete, seguro e outras despesas.
- Organização dos impostos em uma lista.
- Exibição dos resultados dos cálculos.

## Estrutura do projeto

- `Imposto`: interface que define os métodos de cálculo e descrição.
- `PIS`: implementação do cálculo do PIS.
- `IPI`: implementação do cálculo do IPI.
- `Pagamentos`: gerenciamento da lista de impostos.
- `SistemaImposto`: classe principal da aplicação.
