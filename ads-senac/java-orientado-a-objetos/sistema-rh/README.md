# SistemaRH — Gerenciamento de Funcionários


O SistemaRH é uma aplicação desenvolvida para simular o gerenciamento de funcionários de uma empresa, permitindo cadastrar diferentes tipos de colaboradores e calcular suas respectivas remunerações.

O sistema trabalha com funcionários assalariados e horistas, considerando as particularidades de cada modalidade de pagamento.

## Funcionalidades

- Cadastro de funcionários.
- Organização dos dados em uma lista de funcionários.
- Exibição das informações dos colaboradores.
- Cálculo de remuneração para funcionários assalariados.
- Cálculo de remuneração para funcionários horistas.
- Aplicação de aumento percentual nos salários.

## Estrutura do projeto

O projeto utiliza as seguintes classes:

- `Funcionario`: classe abstrata que representa os dados e comportamentos comuns dos funcionários.
- `Assalariado`: representa funcionários que recebem salário mensal.
- `Horista`: representa funcionários remunerados por hora trabalhada.
