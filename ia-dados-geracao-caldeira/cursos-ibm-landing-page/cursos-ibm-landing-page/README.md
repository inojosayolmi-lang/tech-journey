# Cursos IBM — Landing Page

Landing page desenvolvida como projeto individual durante o programa Geração Caldeira, inspirada nos cursos e conteúdos de capacitação em tecnologia oferecidos pela IBM por meio da iniciativa.

O projeto tem como objetivo demonstrar, na prática, a criação de uma página de divulgação de cursos com formulário de inscrição e integração entre ferramentas de automação e comunicação.

## Funcionalidades

- Apresentação de uma trilha de aprendizagem em Inteligência Artificial.
- Seções sobre tecnologias emergentes, desenvolvimento web e fundamentos de IA.
- Formulário de inscrição com nome completo e e-mail.
- Integração com SendPulse para recebimento dos dados e comunicação com inscritos.
- Automação do fluxo de inscrição utilizando Make.
- Envio de uma sequência de e-mails educativos sobre Inteligência Artificial.

## Tecnologias e ferramentas

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Make
- SendPulse

## Objetivo

Colocar em prática conhecimentos de desenvolvimento web e integração de ferramentas, demonstrando como uma landing page pode conectar formulários a serviços externos para automatizar processos de inscrição e comunicação.
